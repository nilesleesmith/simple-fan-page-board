# 21 Savage Fan Page & Message Board

A fan page where visitors can post messages about 21 Savage and interact with messages on the board.

## Overview

This project combines a simple fan page with a message board backed by MongoDB. Visitors can view existing messages, submit a name and message, and use the available controls to vote on or delete messages.

## Features

- Display messages stored in MongoDB
- Submit a name and message
- Display message vote counts
- Provide upvote, downvote, and delete controls

*Note: The voting functionality needs further testing and correction.*

## Run Locally

**Requirements:** Node.js, npm, and a MongoDB database.

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project directory:

   ```bash
   cd simple-fan-page-board
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Configure the MongoDB connection in `server.js` to use your own database credentials. Keep credentials out of committed source code.

5. Start the server:

   ```bash
   npm start
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
